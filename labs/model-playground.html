Lab concept guide

What to observe while you experiment

Different problem types need different experiments: classification requires decision/probability evidence, regression needs fitted values and residuals, clustering has no supervised target, and dimensionality reduction changes representation. The specialised workbenches keep those meanings separate.

MechanismChoose the problem type first, then use the corresponding workbench whose controls, visuals and metrics match that target structure.
Failure modeUsing a metric or visual from one problem type as if it had the same meaning in another.
VerificationBefore entering a workbench, state the target type (or absence of target), expected output and one valid evaluation/diagnostic method.
Experiment deliberately
Pick two different problem types and explain why the same “accuracy”, residual or cluster visual cannot be reused unchanged across them.
