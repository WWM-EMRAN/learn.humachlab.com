Debugging & diagnosis

Correct code can still produce a wrong conclusion.

Each challenge hides a different failure: syntax/control flow, experimental leakage, or model diagnosis. Predict the problem before revealing the explanation.

Lab concept guide

What to observe while you experiment

Debugging means locating the first assumption that became false—not merely silencing an error message. Bugs can be syntactic/runtime failures, experimental-design errors such as leakage, or modelling failures such as overfitting and misleading metrics.

MechanismPredict the failure category, inspect the smallest relevant state/evidence, and trace backward from the symptom to the first incorrect assumption.
Failure modeChanging several lines/settings at once until the symptom disappears, without learning which change fixed the cause.
VerificationReproduce the bug on the smallest case, change one thing, and confirm that the predicted symptom changes for the reason you expected.
Experiment deliberately
For each challenge, write your suspected cause and one diagnostic check before revealing the explanation. Compare diagnosis with the evidence.
Challenge 01 · Python

Why does the loop fail?

values = [3, 5, 8]
for i in range(len(values))
    print(values[i])

Diagnosis: Python block statements end with :. The corrected line is for i in range(len(values)):.

Challenge 02 · Leakage

Why is the validation estimate optimistic?

# Step 1 — Fit the model or transformer, learning its parameters from the supplied training data.
scaler.fit(X)
# Step 2 — Apply the already-fitted transformation without relearning its parameters from this data.
X_scaled = scaler.transform(X)
# Step 3 — Split examples into separate development/evaluation partitions before any leakage-prone fitting occurs.
X_train, X_test = train_test_split(X_scaled)

Diagnosis: preprocessing was fitted before the split. Fit the scaler on training data only—preferably inside a pipeline evaluated by the validation procedure.

Challenge 03 · Model behaviour

What pattern do these scores suggest?

Training accuracy 99%Validation accuracy 64%

Diagnosis: the large train–validation gap is a classic high-variance signal. Check complexity, regularisation, data size, leakage and split validity before blindly tuning more parameters.
