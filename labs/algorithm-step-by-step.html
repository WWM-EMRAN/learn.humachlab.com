Algorithm Step-by-Step Mode

Slow an algorithm down and inspect the sequence of operations that is usually hidden inside a single fit or transform call.

Lab concept guide

What to observe while you experiment

An algorithm that looks like one call in a library is usually a sequence of state changes: choose a candidate operation, update an internal quantity, test a stopping rule, and repeat. This lab exposes that sequence so you can connect the final result to the operations that produced it.

MechanismAdvance one step at a time and record which data, parameter or model state changes at that step.
Failure modeJumping straight to the final state and assuming you understand the algorithm because the output looks plausible.
VerificationPredict the next state before clicking Step, then compare the prediction with the actual update and explain any mismatch.
Experiment deliberately
Reset, choose a tiny problem, and narrate three consecutive updates. Then change one control and predict which step in the sequence should change first.
