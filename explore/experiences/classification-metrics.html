Why can “90% accuracy” be terrible?

Build the mental model

Metrics encode which mistakes matter. Accuracy treats all correct decisions equally; precision, recall, F1, ROC-AUC, PR-AUC and log loss answer different questions. Start from decision costs and class prevalence. For rare positives, PR curves and precision/recall are often more informative than accuracy.
