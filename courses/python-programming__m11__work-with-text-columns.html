Textbook walkthrough

Work with Text Columns

pandas string accessors apply text operations element-wise to a Series while preserving row alignment. Operations such as .str.strip(), .str.lower(), .str.contains() and .str.extract() are designed for tabular text cleaning and filtering, including missing values that would make ordinary Python string methods awkward across a column.

Learning goal: explain why Work with Text Columns behaves this way, apply it to a small example, and verify the result independently. Begin by being able to justify this first step: Inspect the original values and missingness.

# Step 3 — Compute the right-hand expression and store its result in `clean` for the next step.
