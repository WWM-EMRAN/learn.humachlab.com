Mathematical & Statistical Foundations

Review the mathematical ideas that appear repeatedly in analytics and machine learning: probability, statistics, linear algebra, optimisation, loss functions and generalisation. The topic is split into focused lessons so definitions, implementation decisions, diagnostics and common failure modes can be learned separately.

How to use this topic

Learn the mechanism one decision at a time

Work through the lessons in order if the topic is new. If you already know the basics, open the specific leaf lesson that matches the operation, diagnostic or failure mode you need.
