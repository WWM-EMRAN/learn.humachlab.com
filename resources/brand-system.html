Configurable visual identity

Ten learning-inspired HumachLearn marks. One connected identity.

The icon set uses books, notebooks, writing tools, study symbols and learning metaphors—without letter monograms. HumachLearn chooses one icon at random on each refresh; edit config/site-config.js to lock one mark or change the rotation mode.
